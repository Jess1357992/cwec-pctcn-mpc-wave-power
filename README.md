# CWEC–PC-TCN–MPC: spectrum-driven wave power, physics-conditioned forecasting and hard-constrained flywheel control

Data, trained models and code accompanying the manuscript:

> Ou, T.-C., Chen, Y.-T., Ju, Z.-C., Luo, S.-Y. *Linking channel resonance to
> forecast-assisted power smoothing in a coastal wave energy converter with flywheel
> energy storage.* Submitted to **Ocean Engineering**.

Everything reported in the manuscript is generated by the scripts in `code/` from the
dataset in `data/`. No result is hand-entered.

## What is in this repository

| Path | Description |
|---|---|
| `data/spectrum_realizations_demo.npz` | 96 electrical-power realizations, 6000 samples each (600 s at 10 Hz), with the physical context of every record and the train/validation/test assignment. |
| `data/manifest_demo.csv` | One row per realization: sea state, resonance ratio, damping, split, seed and summary statistics. |
| `data/data_dictionary.md` | Field-by-field description of both files. |
| `code/` | Dataset generation, model definition, training, baselines, controller, and the analyses behind every figure and table. |
| `models/` | Trained weights and normalization constants for PC-TCN and the four neural baselines, training seed 42. |
| `results/` | The numerical outputs quoted in the manuscript: forecast metrics, paired comparisons, closed-loop metrics, lead-time thresholds and energy-period sensitivity. |

## The dataset in one paragraph

Irregular sea states are synthesized from a Pierson–Moskowitz variance-density spectrum
with independent random phases. Each surface-elevation record is passed through the
single-degree-of-freedom frequency response of the converter's tapered collection channel,
and the rectified channel velocity is converted to electrical power by a single wave-to-wire
coefficient that is calibrated once at a baseline sea state and then held fixed for every
record. Because the coefficient is never refitted per realization, differences in mean power
and in temporal structure between sea states remain in the data instead of being normalized
away. The grid spans significant wave heights of 0.060 and 0.090 m, energy periods of 1.40
and 1.75 s, resonance ratios of 1.00, 1.60 and 2.10, and damping ratios of 0.10 and 0.20 —
24 combinations with four random-phase realizations each.

Complete physical scenarios, not overlapping windows, are assigned to training, validation
and test in a 50:25:25 split, so the test grid is unseen during both fitting and checkpoint
selection.

## Reproducing the results

```bash
pip install -r requirements.txt

python code/generate_dataset.py --profile demo          # writes data/
python code/train_pctcn.py --model pctcn --seed 42      # and tcn / gru / rnn / cnn_rnn
python code/run_classical_baselines.py                  # persistence, climatology, ridge/AR(156)
python code/validate_model_comparison.py                # Table 5, Fig. 9
python code/run_hard_mpc.py                             # Table 6, Fig. 10
python code/analyze_prediction_limits.py                # Section 5.1
python code/test_te_context_error.py                    # Section 5.2
python code/make_submission_figures.py                  # Figs. 7, 8
python code/make_te_error_figures.py                    # Fig. 11
```

Training used TensorFlow/Keras on CPU. Re-running `train_pctcn.py` overwrites `models/`;
the weights committed here are the ones used for every number in the manuscript.

## Scope

The electrical power is synthetic. The study is a numerical proof of concept: one training
seed and one representative closed-loop case are reported, and the ordered forecast outputs
are used as scenarios rather than as calibrated uncertainty intervals. Section 5 of the
manuscript quantifies where forecast quality degrades.
